# Prompt utilizado para el algoritmo

> Escribe un programa en Python que pida tres números enteros y los muestre de menor a mayor. Usa solo input, if, else y comparaciones: sin listas, ciclos ni sorted(). Explica en tres líneas cómo funciona.

Se utilizan `int` para convertir las entradas y `print` para mostrar el resultado, como en la plantilla de clase. La lógica de ordenamiento se resuelve con decisiones y comparaciones.

Programa elegido: [ordenar.py](ordenar.py). Las alternativas aportadas por el estudiante se identifican como Gemini y Claude en el registro de pruebas.
